# v1.0 AI-Native 交易架构设计

> 状态:设计定稿,待实施
> 作者:系统 + 用户方向性输入
> 日期:2026-10-09

## 0. 为什么重新设计:v0.4-v0.8 的三个实验事实

我们的测量体系(回放/反事实/零智能对照)给出了三个不容回避的事实:

1. **双模型等价**:glm-4.5-flash 与 glm-4.5-air 在完全相同窗口、
   相同 prompt、相同门控下,组合结果统计不可区分
   (-0.20% vs -0.20%,maxDD 0.23% vs 0.24%)。
2. **零智能等价**:纯 EMA 交叉 + 动量规则提议器,过同样的门,
   结果同样不可区分(-0.20%,maxDD 0.25%)。
3. **多头偏见是任务层现象**:两个模型多空比都是 ~2.4:1,
   亏损都集中在 TRENDING_BULL LONG。

结论:不是模型不行,是**系统设计把 AI 压缩成了规则引擎**——
同样的输入(纯技术特征)、极小的决策空间(5 动作 × 5 币)、
5 道确定性门把任何判断差异抹平。AI 的智能没有发挥的余地。

v1.0 的设计目标:**在不牺牲安全底线的前提下,最大化 AI 的
信息优势、知识深度和决策权重,并用实验测量每一项的增量。**

## 1. 设计哲学转变

| | v0.4-v0.8(提议-否决) | v1.0(AI-Native) |
|---|---|---|
| AI 角色 | 被审批的提议者 | 风险预算内的全权决策者 |
| 信息 | 技术特征(和规则相同) | 全情报栈 + 知识库 + 记忆 |
| 知识 | 无 | 交易大师 playbook + 自身复盘经验 |
| 约束方式 | 硬门控逐条否决(LLM 无法预见) | 风险沙箱(边界内自由,边界硬) |
| 出场 | 固定 ATR 屏障 | AI 定义 thesis + invalidation,屏障兜底 |
| 仓位 | 固定波动率目标 | AI 按信心分档(沙箱上限内) |
| 流程 | 单次调用出 JSON | 研究 → 决策 → 自我反驳 三阶段 |
| 验证 | 同左 | 每个能力单独 A/B,null test 保留 |

一句话:**把"聪明的否决"换成"聪明的决策 + 算术的兜底"。**

什么留在确定性层(永远不给 AI):
- 交易所连接、订单执行(Hummingbot)
- 手续费/滑点计算(Cost Validator 是算术,不是判断)
- 风险沙箱的物理边界(见 §5)
- PAPER/TESTNET/LIVE 隔离、凭证保护

什么交还给 AI(v0.8 的硬门控降级为"参考信号"):
- 入场时机(v0.8 的回调门/死市守卫从"否决"改为"提示",
  AI 可以看到这些指标的数值和自己的历史表现,自主权衡)
- 币种选择(横截面排名从"只允许 top2"改为"参考排名")
- 策略选择与参数
- 出场判断(thesis 失效即出场,不必等止损)

## 2. 信息层:给 AI 规则系统看不到的东西

零智能对照证明:纯技术特征上 AI 无法胜过规则。AI 的潜在优势
在于**多源信息的综合判断**。v1.0 的全情报栈(采集器已在运行):

```text
市场微观结构:  price/OHLCV/价差/订单簿失衡/成交结构
衍生品情报:    funding 及偏离度、OI 及变化率、清算热力、基差
链上情报:      交易所净流入/流出、大额转账、稳定币流、活跃地址
社交情报:      社交量及 z-score、情绪及变化、创作者活动、趋势排名
新闻事件:      分类事件流(ETF/监管/上币/黑客/升级),去重+摘要+时效
叙事引擎:      跨源确认的市场叙事及强度/新颖度/动量
宏观日历:      (可选)CPI/FOMC 等事件倒计时
```

铁律(沿用 v0.4):
- 所有信息带 timestamp + age_minutes + confidence;
- 原始文本不进 prompt,全部先归一化/聚合/摘要成结构化信号;
- 信息陈旧度由 AI 自己权衡(这是智能该做的事)。

## 3. 知识层:让 AI "学过"交易

当前 AI 每 30 分钟从零判断一次,没有任何"交易技艺"。v1.0 增加
两类知识库,决策时按相关性检索注入:

### 3.1 Playbook 库(短线交易大师知识库)

结构化的策略 playbook,每条包含:

```yaml
- id: funding_squeeze_short
  name: 资金费率挤压做空
  setup: |
    funding 极端为正(多头拥挤)+ 价格滞涨/跌破关键位
    + OI 高位 + 清算瀑布风险积聚
  entry: 跌破 VWAP/前低确认后做空
  invalidation: funding 回归中性或价格收复关键位
  management: 分批止盈,跟随清算级联
  failure_modes: 强势牛市中 funding 可以长期极端,逆势过早做空
  best_regime: TRENDING_BULL 末端 / BREAKOUT 失败
  source: 经典短线/订单流战术
```

首批 playbook 候选(短线/波段经典战术):
- 突破与假突破(breakout / breakout-failure / 流动性扫荡)
- 资金费率挤压(funding squeeze,多空双向)
- 清算级联(liquidation cascade 跟随与反转)
- 均值回归(极端偏离 + 量能衰竭)
- 事件驱动(新闻/上币/监管的快速反应)
- 区间震荡做市(grid 的适用与失效条件)
- 趋势跟随(回调入场、金字塔加仓、跟踪止损)
- 横截面轮动(相对强弱切换)

### 3.2 复盘知识库(自身经验)

FinMem/Reflexion 式分层记忆,复用现有 Memory 设施但升级为
**检索式**(当前只是按时间堆叠):

- 每笔交易平仓后自动生成结构化复盘(thesis 是否成立、
  invalidation 是否及时、市场环境、教训);
- 决策时按 (symbol, regime, playbook, setup 相似度) 检索
  相关的历史教训注入 prompt;
- 记忆永远只是上下文,不能自动修改沙箱边界。

## 4. 决策层:三阶段深思熟虑

当前是单次调用出 JSON——对 30 分钟一次的决策频率,
air 的速度(7.9s/次)允许我们负担深得多的推理:

```text
阶段一 研究(Analyst)
  输入:全情报栈 + 相关 playbook + 相关复盘记忆
  输出:市场状态判断、主导叙事、候选机会列表(含 setup 分类)

阶段二 决策(Trader)
  输入:阶段一输出 + 组合状态 + 风险预算余量
  输出:结构化决策,每个仓位必须包含:
    - thesis(为什么这笔交易能赚钱,一句话)
    - invalidation(什么发生了就说明错了,具体价格/事件)
    - playbook 引用或 "no-setup"(无 playbook 支撑需更高信心)
    - 信心档位(映射到仓位档位)
    - 时间地平线(预期持有多久)

阶段三 自我反驳(Critic,devil's advocate)
  输入:阶段二的决策
  输出:对每个拟开仓位提出最强反方论证;
       若反方论证击中 invalidation 已覆盖之外的风险,
       降级信心或放弃
```

三阶段可以是同一个模型的三次调用(总成本约 3×,仍远低于
flash 免费档的拥塞代价),也可以未来做模型分工(研究用强模型、
常规用 air——Model Router 接口已预留)。

**关于多头偏见**:偏见来自训练语料的做多倾向。对策不是门控
(已证明治标不治本),而是:
- prompt 中显式要求每个 LONG 决策附带"为什么不是做空"的论证;
- 复盘知识库沉淀偏见的代价(我们已有数据:TRENDING_BULL LONG
  PF 0.25),检索注入;
- Critic 阶段对 LONG 决策天然多一层审视。

## 5. 风险沙箱:唯一的硬约束层

AI 在沙箱内全权,沙箱边界物理不可逾越(确定性代码):

```text
max_total_exposure      总敞口上限
max_symbol_exposure     单币种敞口上限
max_leverage            杠杆上限
risk_per_trade_max      单笔风险上限(权益占比)
daily_loss_limit        日亏损熔断(触发后当日只允许减仓)
consecutive_loss_halt   连续亏损熔断(暂停并强制复盘)
cooldown_after_stop     止损后冷却(保留,这是执行卫生不是判断)
cost_validator          期望净收益必须为正(算术,不是判断)
PAPER/TESTNET/LIVE      环境隔离(凭证级,AI 永远无权切换)
```

与 v0.8 门控的本质区别:v0.8 的门是"对 AI 的判断进行审批"
(追高否、死市否、横截面排名否);v1.0 的沙箱是"对结果进行
物理限制"(亏多少、敞口多大)。前者压制智能,后者只是护栏。

被降级的 v0.8 门控不删除,转入 **shadow 模式**:继续计算并记录
"如果按 v0.8 会怎么做",用于事后对比 AI 自主判断与规则判断的
各自表现。

## 6. 执行层与出场

- 执行不变:Hummingbot / executor / 模拟成交,全部复用。
- 出场变为双轨:AI 的 invalidation(逻辑止损)在先,
  沙箱的价格屏障(物理止损)兜底。thesis 失效时 AI 主动平仓,
  不必等价格打到屏障——这是 AI 相对规则系统的真实优势点之一
  (规则只能等价格信号,AI 能识别"逻辑变了")。
- time-stop 由 AI 的时间地平线驱动:到点 thesis 未兑现即退出,
   horizon 本身进入复盘评估("判断对但太慢"也是失败)。

## 7. 测量层:每一层增量都要可验证

v0.8 时代建立的测量基础设施全部保留并作为验收标准:

| 实验 | 对照 | 回答的问题 |
|---|---|---|
| null test | rule-proposer(已有) | AI 增量是否存在 |
| A | AI + 仅技术特征(v0.8 等价物) | 基线 |
| B | A + 全情报栈 | 信息增量 |
| C | B + playbook 库 | 知识增量 |
| D | C + 三阶段推理 | 深思增量 |
| E | D + 复盘记忆检索 | 学习增量 |

每个实验:同窗口、同沙箱、同执行器,30d 起。
核心指标:PF、net PnL、maxDD、决策质量分类(沿用 v0.4 的
Good/Bad/Unclear/Execution Failure)、WAIT 质量(不交易的
决定是否正确——事后收益为证)。

**失败处理**:任何一层(B-E)若在 30d 样本上无增量,降权或
关闭该层,回退一层继续。不堆无效复杂度。

## 8. 实施阶段

- **Phase 1 信息进 prompt**:情报栈接入回放 prompt
  (采集器已有,做特征工程与压缩),跑实验 B
- **Phase 2 playbook 库**:撰写首批 8-10 条 playbook,
  实现检索注入,跑实验 C
- **Phase 3 三阶段决策**:研究/决策/反驳三段式,跑实验 D
- **Phase 4 复盘记忆检索**:平仓复盘 → 结构化教训 → 相似度
  检索,跑实验 E
- **Phase 5 沙箱化切换**:硬门控转 shadow,AI 全权,
  沙箱收紧到保守值起步,逐步放宽(每步 A/B)
- **Phase 6 30d/90d 验证 + 报告**

每个 Phase 交付物:代码 + 同窗口实验 + 数据结论。任何 Phase
无增量则停止叠加,诚实记录。

## 9. 风险与反方观点(自我审查)

1. **自由度扩大 = 亏损可能扩大**。v0.5 之前的系统就是这样亏的。
   不同之处在于:这次有情报栈、知识库、三阶段推理和沙箱熔断,
   且每一步都有 A/B 闸门。但如果实验 B-E 全部无增量,最终答案
   就是回退到"规则执行 + AI 研究层"——这也是有价值的结论。
2. **prompt 膨胀**:情报栈 + playbook + 记忆可能让 prompt 过大
   导致注意力稀释。对策:检索式注入(只放相关的),30d 实测。
3. **过度拟合 prompt**:playbook 和 prompt 的调优本身可能
   过拟合历史窗口。对策:90d/多市场环境样本外验证后才允许
   进 LIVE 讨论。
4. **成本**:三阶段 × 富 prompt ≈ 单次决策成本 ×5-8,
   air 定价下仍可忽略(7d 回放约 ¥5-8)。

## 10. 不变量(任何版本不得违反)

- PAPER/TESTNET/LIVE 凭证级隔离,LIVE 只能人工开启
- 沙箱边界由确定性代码物理执行,AI 无权修改
- 历史实验不可修改,新实验新 experiment_id
- Chain-of-Thought 不入库、不上 Dashboard(只存结构化结论)
- 测量先行:没有 A/B 证据的能力不上线
