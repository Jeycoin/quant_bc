# 预注册:增强因子栈 vs 原始栈(同窗口 7d 回放)

日期:2026-10-12

## 假设

H1: 在完全相同的 7 天窗口(2026-09-20 11:00 → 09-27 11:50 UTC)上,
当前栈(36因子 + 价格路径 + v1.2 退出逻辑 + 更新 prompt)的净收益、
最大回撤、决策质量优于原始栈(exp-a856ad913012, 19因子)。

H0: 两者无实质差异(与此前"AI≈规则"的等价证据一致)。

## 设计

- 对照组:exp-a856ad913012(bt-replay-7d,2026-10-01 前代码,旧因子)
- 实验组:同窗口新跑一次,当前 main 代码
- 固定:窗口、五币种、资本 10000、费率、滑点模型、执行模拟器
- 变动(整体栈,非单因子隔离):因子库扩充、价格路径、prompt、
  v1.2 退出逻辑(underwater TIME_STOP)

注意:这不是因子单变量消融(退出逻辑和 prompt 同时变了),
是"系统整体是否改善"的检验。单因子隔离需后续 counterfactual 分解。

## 判决规则

- 采纳:实验组 net PnL 改善 >= 0.5% 且 maxDD 不劣化,且
  ENTRY/COST/RISK 拒绝记录显示新因子被实际引用(evidence 文本抽查)
- 否决:无显著差异或更差 → 因子扩充无增量,回退讨论
- 样本小(7d),结论仅为指示性,不作为最终证据
