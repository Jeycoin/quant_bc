# 预注册:v1.2 退出逻辑 A/B(TIME_STOP churn 修复)

> 日期:2026-10-10
> 状态:预注册,先于实验
> 依据:docs/reports/2026-10-10-30d-replay-report.md §2.3 / §5.1

## 假设(H)

30d 回放(exp-ce0220fe8b87)中,position_executor 的退出结构为:

| 平仓方式 | 笔数 | 净盈亏 |
|----------|------|--------|
| STOP_LOSS | 17 | -65.08 |
| TIME_STOP | 88 | -24.10 |
| TRAIL_EXIT + TAKE_PROFIT | 11 | +47.57 |

**假设:6 小时无条件 TIME_STOP 通过两种机制摧毁期望值——
① 把浮盈/持平但尚未触及 +1x SL 的仓位按市价踢出(白付手续费);
② 在入场 regime 仍然成立时杀死慢趋势(趋势还没走完就被时间踢掉,
冷却后重新进场,形成 churn)。**

## 实验设计

复用 exp-ce0220fe8b87(30d,09-09~10-09)的全部已记录 LLM 决策,
以反事实模式重放,只改退出逻辑。入场、门控、费用、仓位全部不变。
LLM 零调用,完全确定性。

| 组 | 退出逻辑 | 说明 |
|----|----------|------|
| V0 | 现状(6h 无条件 TIME_STOP) | 基线 = exp-8a69cf61be6b(已跑,-0.40%) |
| V1 | **主假设**:TIME_STOP 只在浮亏时触发 | 浮盈/持平仓位持有到 TP/trail/24h 硬顶 |
| V2 | 敏感性:TIME_STOP 窗口 6h→12h | 仍无条件 |
| V3 | 敏感性:TIME_STOP 只在浮亏 **且** 入场 thesis 失效时触发 | thesis 存活 = 当前 regime 与持仓方向一致(LONG←TRENDING_BULL/BREAKOUT/HIGH_VOLATILITY;SHORT←TRENDING_BEAR/HIGH_VOLATILITY) |

稳健性检查:主假设 V1 在 7d 下跌窗口(exp-f6fef0b4c90d 的决策)上重跑一次,
确认不是在单一窗口过拟合。

## 主指标与判决规则(先于数据写下)

- **主指标**:agent position_executor 净 PnL(30d 窗口);
- **次要指标**:TIME_STOP 笔数、交易总数、avg win / avg loss、maxDD、费用合计;
- **采用规则**:V1 同时满足 ① 净 PnL 优于 V0(超出费用节省下限),
  ② maxDD 恶化不超过 0.2 个百分点,③ 7d 窗口上不归零收益结构
  → 采纳为默认;否则保留现状;
- **V2/V3 即使跑赢也不直接采纳**——标记为探索性发现,需在下一个
  独立窗口验证后才允许成为默认(防同窗口多重比较过拟合)。

## 不变量

- 历史实验(exp-ce0220fe8b87 等)不修改;本实验全部使用新 experiment_id;
- 只改退出逻辑,不动门控、不动 cost_validator、不动仓位计算;
- 若所有变体相对 V0 差异 < 0.1 个百分点:结论写"退出逻辑不是一阶问题",
  停止此方向,不继续微调参数。

## 机制归因(平仓方式分解)

| close_type | V0 笔数/净额 | V1 笔数/净额 |
|---|---|---|
| TIME_STOP | 87 / -23.75 | 64 / -58.14 |
| TAKE_PROFIT | 3 / +24.29 | **12 / +56.38** |
| TRAIL_EXIT | 8 / +23.28 | **15 / +36.77** |
| TIME_LIMIT | 1 / +4.12 | 5 / +15.13 |

机制确认:无条件 TIME_STOP 在慢趋势触及 +1x SL 激活线之前就将其踢出;
改为只踢浮亏仓位后,更多仓位活到 TP/trailing(+32/+13.5),
TIME_STOP 剩余的都是真亏损单(本就该踢)。

## 判决(对照预注册规则)

- V1 净 PnL 改善 +0.35pp(> 0.1pp 实质下限)✅
- maxDD 0.36% vs 0.52%,未恶化 ✅
- 7d 独立窗口同样改善(-0.20% → -0.05%)✅

**→ V1(underwater)采纳为默认**(--time-stop-mode 默认值已改;
TIME_STOP 仅存在于回放 harness,实盘路径无此逻辑,无实盘影响)。

- V3(regime,+0.01%)按预注册规定**仅标记为探索性发现**——
  比 V1 多赚的 +0.07pp 来自同窗口多重比较,需下一个独立窗口复验后才可考虑。
- V2(12h)差于 V1,否决。

## 附带发现并修复的存储缺陷

实验过程中发现 trade_events 以 executor_id 单列为主键,
反事实重放与源实验共享 id 导致 INSERT OR REPLACE 跨实验覆盖
(exp-8a69cf61be6b 的行被后续变体覆盖)。
修复:回放生成的 executor id 追加 @experiment_id 命名空间
(commit 同批)。历史实验的 summary_json 不受影响(以实验 id 为键);
早期 trade_events 行已被覆盖,以各实验 summary 为准。
本节 4 组数字来自修复后的干净重跑。
